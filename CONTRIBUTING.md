# Вклад в проект

Спасибо за интерес к материалам курса. Небольшие исправления, новые тесты и улучшения объяснений особенно полезны.

## Перед pull request

1. Создайте отдельную ветку с понятным именем.
2. Сохраните стиль исходного файла и не смешивайте несвязанные изменения.
3. Добавьте или обновите тест, если меняется поведение алгоритма.
4. Из каталога `python/` выполните:

```bash
python -m unittest test_core.py test_optim_extra.py test_qp_reference.py
```

## Что стоит включить в описание PR

- какую проблему решает изменение;
- какие файлы и алгоритмы затронуты;
- как выполнена проверка;
- есть ли изменение в выводе примеров или API.

Не добавляйте сгенерированные `__pycache__`, виртуальные окружения и локальные результаты запусков.
